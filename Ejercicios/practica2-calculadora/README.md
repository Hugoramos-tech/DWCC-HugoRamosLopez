# Práctica 2: Calculadora de notas

Calculadora que aplica un 70 % a la nota del examen y un 30 % a la práctica.

## Puntos a mayores

- Validación de notas entre 0 y 10.
- Actualización del resultado mientras se escriben las notas.
- Cálculo de la nota mínima necesaria en el examen.
- Historial guardado en localStorage y botón para borrarlo.
- Calificación en texto.
